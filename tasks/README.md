# Задачи

**Один сервис заказов, много адаптеров.**\
Бизнес-логика — размещение, оплата, отмена заказа — написана один раз. Шаг за шагом под неё подключаются разные базы, брокеры, кэш, поиск и аналитика.

**Каждая задача — это ветка `step-NN` и PR в `main`.**\
PR (pull request) — запрос на слияние ветки в `main`. В нём код шага, тесты и ADR вместе.

---

## Лестница

**Подпорки снимаются постепенно.**\
Сначала читаешь готовое, потом заполняешь дыры, потом пишешь половину, потом всё сам.

| Уровень | Что дано |
|---|---|
| 🟢 полный пример | всё работает; читаешь, запускаешь, отвечаешь на вопросы, делаешь маленькое расширение |
| 🟡 дыры | адаптер почти готов, несколько методов — `todo.Step(...)` |
| 🟠 половина | контракт-тест и сигнатуры даны, реализация пустая |
| 🔴 сам | дан только порт (или вообще ничего): пакет, тесты, иногда и порт — твои |
| 📖 теория | кода нет, только ADR |

## Как устроена каждая задача

| Блок | Что в нём |
|---|---|
| **Цель** | что должно получиться |
| **Теория** | что прочитать до кода — со ссылками на разделы |
| **Что дано** | какой код уже есть и что в нём не хватает |
| **🤔 Подумай до кода** | вопросы, на которые стоит ответить ДО реализации; ответы идут в ADR |
| **Что сделать** | пошагово, что написать |
| **✅ Definition of Done** | команды, которые должны пройти |
| **ADR** | какое решение записать |
| **🎤 Вопросы на защите** | к ним готовься устно |
| **Словарик** | термины задачи со ссылками в теорию |

**Ссылка 📖 после 🤔 вопроса — где в теории объяснена механика.**\
Готового ответа там нет: теория объясняет, как устроена технология, а применить это к нашему сервису — твоя часть работы.

**🤔 — до кода, 🎤 — после.**\
🤔 вопросы помогают не написать код вслепую. 🎤 проверяют, понимаешь ли ты, что написал и почему.

## Как понять, что шаг сделан

**Заглушки возвращают `todo.Step("NN")`, контракт-тесты показывают их как SKIP.**\
Поэтому `make check` зелёный даже на несделанном шаге ([10-testing, раздел 5](../docs/theory/10-testing.md#5-skip-вместо-fail-для-недописанного)).

**Шаг сделан, когда выполнены оба условия:**

```sh
make check                                                       # зелёный
go test -tags=integration -v ./internal/infrastructure/<pkg>/ | grep SKIP   # пусто
```

**Плюс команды из ✅ Definition of Done задачи и ADR в PR.**\
У некоторых шагов DoD строже: например, у Kafka тесты нужно прогнать пять раз подряд.
